# Research and correction protocol

- Record a stable ID, date, contributor, exact original statement, evidence class, sources, assumptions, counterevidence, proposed tests, and confidence.
- Distinguish **observation → interpretation → mechanism → prediction → test → result**.
- Preserve negative findings and failed predictions, not only successes.
- Record a correction as a new entry linked to the earlier statement; do not delete the earlier statement.
- Label assistant-generated paraphrases as reconstructions; only mark text verbatim if exact wording was retained.
- For scientific references, prefer original articles or authoritative reviews; distinguish a bibliographic lead from a checked citation.
- For agent contributions, identify the model, date, task, tools, and scope of access; never imply model consensus from one model's output.
- Never run experiments on living organisms or post to external agent communities without explicit approval and applicable oversight.
